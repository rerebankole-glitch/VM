      LESS STORAGE. MORE CLARITY.

      Your disk doesn’t need the ISO.

      Stream an image: the ISO stays on its host. The browser fetches the blocks the guest reads. Streaming-only mode is on by default and refuses a full download when streaming is unavailable.

      Still local computing: emulation uses your CPU and RAM. Browser caches can use some space. Guest files are temporary unless you explicitly save a snapshot or disk. “Save session here” is optional local storage, not cloud storage.

      Why not the latest Linux Mint?

      v86 emulates a 32-bit x86 CPU. Mint 20 and newer need a 64-bit CPU. Mint 19.3 Xfce is an old compatible candidate, but is unsupported and can be very slow. Compatibility is not a guarantee of a successful boot.

      Linux with a browser, without an ISO

      The built-in Alpine Linux + Dillo desktop loads small compressed files from this site as needed. It has a real graphical browser and terminal. Dillo does not run JavaScript; internet needs an optional relay, and guest work stays temporary.
