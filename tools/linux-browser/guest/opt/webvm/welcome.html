Your Linux browser is running.

This is Dillo inside a real 32-bit Alpine Linux desktop, not a browser window painted by the website.

A small Linux computer, no giant ISO

Linux loads its filesystem from this Pages site as files are needed. Your browser supplies the CPU and RAM. No installer or ISO file needs to be saved on your computer.

Try it

  • Type a URL in Dillo's address bar, or open a second local page.
  • Right-click the blue desktop for a terminal and app menu.
  • Click the guest display to control it. Ctrl+Alt+G releases the controls.

Internet is optional

The first page is local and works without internet. To visit websites, power off and choose Machine → Network → Public relay or your own trusted relay before booting. A public relay is a third-party service: do not send private data.

Dillo supports basic HTML, images and HTTPS, not JavaScript. Complex web apps, videos and account sign-ins may not work. For full modern web browsing, use current 64-bit Linux Mint or another desktop with Firefox on a remote computer.

Temporary by default

Guest changes live in the tab's memory and disappear when you power off or close the tab. This lightweight desktop has no automatic persistent disk. Package-management and GPU features are intentionally trimmed.
