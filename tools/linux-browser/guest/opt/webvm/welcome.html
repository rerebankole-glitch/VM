WEBVM LINUX · Alpine 3.23 · widescreen desktop

Your Linux computer is running.

This is a real 32-bit Alpine desktop inside the emulator — Fluxbox, a terminal, and the Dillo browser. It is not a picture of a desktop painted by the website.

Try it

  • Type a URL in the address bar, or open a second local page.
  • Right-click the desktop for the browser and a terminal.
  • Click the guest display to control it. Ctrl+Alt+G releases the controls.

About the browser

The bundled browser is Dillo. It handles basic HTML, images and HTTPS. It does not run JavaScript, so Firefox-class sites (accounts, video, web apps) will not work here.

A current Firefox cannot fit in this 32-bit, 256 MB guest. Mozilla also ended normal 32-bit Linux Firefox builds. For Firefox, use a 64-bit remote Linux VM, or stream the experimental antiX 32-bit ISO from the catalogue.

Internet is optional

This page is local and works offline. To visit websites, opt into the public relay on the WebVM welcome card, or pick your own relay under Machine → Network before booting. A public relay is a third-party service: do not send private data.

Temporary by default

Guest files live in this tab's memory. Power off or close the tab and they are gone. There is no automatic disk.
